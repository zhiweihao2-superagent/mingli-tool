# 八字工作台视觉方向一

状态：待用户确认，不是最终品牌定稿。

## 方向名称

节律历表

## 核心判断

界面借鉴现代历表、学术年鉴与精密印刷物的秩序感，而不是古卷、星空、八卦背景或深色“玄学仪表盘”。用户首先看到一件可靠的计算工具，随后才感受到东方历法文化。

## 第一屏

左侧是可逐项完成的出生资料表单，右侧是四柱结果工作区。尚未计算时，年、月、日、时四个位置以清晰空位呈现；计算完成后，一条“节律线”依次连接四柱并落定结果。移动端改为先填写、后查看，操作按钮始终在拇指可达区域。

## 视觉系统

- 基底：冷静的矿物灰纸色，不使用仿旧纹理。
- 主色：深墨蓝绿，承担导航、主要操作和重要文字。
- 强调：克制朱砂色，只用于当前步骤、警告和关键定位。
- 结构：细规则线、对齐标记和表格节奏体现可追溯性。
- 字体：以可靠的中文系统黑体为主，结果干支使用衬线中文回退；不把等宽字体当“技术感”装饰。
- 圆角：接近直角，只用于真实控件与分组边界，不把每段内容包成卡片。

## 标志性交互

计算完成后，四柱之间的节律线从年柱向时柱完成一次 240ms 的定位动画，并立即停止。它表达“计算已落定”，不是装饰性循环。减少动态偏好下完全禁用。

## 初学者策略

- 先显示四柱、日主、起运方向和警告。
- 藏干、神煞、完整大运和流年通过标签页渐进展开。
- 每个未知或不支持项都在结果附近解释，不用空白或默认值掩盖。
- 错误同时出现在表单顶部摘要与对应字段附近，并把焦点移到摘要。

## 风险

历表和印刷秩序容易显得过于理性。通过轻微矿物色温、适度留白和自然中文文案缓和，但不会牺牲工具可信度去增加玄学装饰。
