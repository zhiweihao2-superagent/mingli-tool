# 起紫微与主星落宫的边界校验

- 盘数：2016（1990–1995 全年 × 12:30 男；单年补不满 5 局 × 30 日，故扩到六年）
- 起紫微比对：2016 次，差异 0 次
- 主星偏移失败：0 条（上限 20）
- 覆盖完整性：5 局 × 30 日全部覆盖

## 公式

```
q = ceil(d / n)   // n = 局数，d = 农历日
r = n*q - d
紫微 = 寅 + (q-1) ，再按 r 进退：r 奇 → 逆退 r 宫；r 偶（含 0） → 顺进 r 宫
```

无。公式与引擎在全部覆盖到的（局, 日）组合上一致。

## 主星偏移

断言 12 条：天机 −1、太阳 −3、武曲 −4、天同 −5、廉贞 −8（相对紫微）；太阴 +1、贪狼 +2、巨门 +3、天相 +4、天梁 +5、七杀 +6、破军 +10（相对天府）。

全部成立。

## 边界

- 公式是「通行口径」，不是文墨天机的内部实现；本校验证明的是「引擎与通行公式一致」，不是「引擎与文墨天机逐日一致」。
- 若要证明后者，需要文墨天机逐日导出（每种局 30 张，共 150 张）。
- 农历日取自引擎自身输出，若农历转换本身错，这条校验会一起错。
