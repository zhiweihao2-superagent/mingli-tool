# 计算规则

当前规则配置编号为 `bazi-skill-112a5d84-beijing-v1`。

- 时区：北京时间 UTC+8。
- 年柱边界：精确立春时刻。
- 月柱边界：十二节，不按农历初一换月。
- 日柱边界：23:00 起按次日日柱，00:00 至 00:59 为早子时。
- 只提供“子”时辰而没有分钟时，按早子时处理并产生警告。
- 时柱未知时不补造默认时柱，依赖时柱的神煞也不使用虚构值。
- 大运顺逆：阳年男和阴年女顺排，阴年男和阳年女逆排。
- 起运：出生时刻到相应“节”的天数除以三，按上游规则折算年月。
- 真太阳时：仅在用户填写经度后启用。按“东八区钟表时 + 经度差修正 + NOAA 均时差近似”计算，允许跨日；八字与紫微共用同一个校正结果。
- 夏令时：不自动猜测。只有用户明确勾选“出生证明记录的是夏令时钟表时间”时，先减 60 分钟再做经度与均时差校正。

更完整的算法说明保留在 `scripts/pai_pan.py` 文件头及 `references/`。这些规则属于当前引擎口径，不代表所有命理流派采用相同约定。
