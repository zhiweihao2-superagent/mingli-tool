# lab2 · 三个「一看就是算命」的排版方向

lab/ 那三套（仪表盘 / 杂志 / 原生）被否了——原因是它们看着像现代 App，不像算命。
lab2 换思路：不比配色、不比组件，直接比**版式母体**。三套用同一组四种颜色（纸黄、墨、朱砂、淡墨），
差别全在「信息按什么规矩排」。

| 方向 | 一句话 | 每屏的样子 |
| --- | --- | --- |
| **D 盘面** | 命盘当主角，今日页有一张太极八卦 + 算盘的封面底纹 | 紫微是整屏 4×4 标准盘位（上巳午未申 / 中左辰 / 中右酉 / 下左卯 / 下右戌 / 下寅丑子亥），中央写局、命主、来因、斗君，盖「命」章；每宫自上而下：大限 → 宫名（朱）→ 主星［亮度］+四化方框 → 辅星 → 流年 |
| **E 命书** | 竖排手卷 | 正文 `writing-mode: vertical-rl`，右起竖读，右侧错落朱批；八字四柱竖排；紫微不画盘，改成十二条竖列宫位名录，大限岁数横排收在名录下方 |
| **F 通书** | 全页表格 | 一切皆格：八字是十行排盘表（干神/天干/地支/藏干/支神/纳音/空亡/地势/行运），干支 30px；大运横排，当前步实心朱底；紫微十二宫排成四列三行表 |

## 硬约束（三套共同）

- 只用四色：`--paper #F0E5CB`、`--ink #1A140F`、`--zhu #A32B1C`、`--faint #5B4F43`。
- 字体只准宋/明体（`Songti SC / STSong / SimSun / Source Han Serif SC`），数字英文同一栈。
- 不许圆角（印章除外）、不许阴影/渐变/毛玻璃、不许 emoji 与图标字体、不许英文装饰小标题。
- 双线框（2px + outline 1px offset 3px）用来分区块，代替卡片。
- 不联网、无外链资源。
- 数据全部来自同一份样盘（1990-05-15 12:30 男，2026 丙午年），三套数字必须一致；缺的数据写「—」，不编。

## D 的今日封面

`d-chart-home.html` 首屏是一张 196px 高的 `cover`，底纹来自 `d-cover.svg`（由 Codex 生成，6055 字节，已内联进 HTML）。

- **太极**：圆心 (258,74)，半径 21，真实阴阳分割（S 形路径，阳在左实心、阴在右留白，两点互嵌）。
- **先天八卦**：同心的三个刻度环（21 / 30 / 60），八组三爻从正上方顺时针排：乾 111 · 巽 011 · 坎 010 · 艮 001 · 坤 000 · 震 100 · 离 101 · 兑 110；爻线垂直半径，由内向外依次是初、二、三爻。
- **算盘**：x 196–342、y 146–184，双线外框 + 加粗横梁，九档，第 3、7 档梁上只一颗珠。
- 左侧 x 0–190 留白，「今日」压在这里；右侧竖排农历。整个图案 `currentColor` + `opacity: .15`，跟着 `--ink` 走，换主题不用换图。
- 底纹只是装饰，不放判据；`cover-sub` 两行小字（虚岁/大限、流年/命宫）才是数据。

## 八字的八卦罗盘

`d-chart-bazi.html` 的版序是**盘在上、四柱表在下**：盘当主角，四柱表是它的注脚。整段由 `.pair/gen-bazi-dial.cjs` 生成（改数据只动脚本里的 `PILLARS`，别手改 SVG）。

规则是**只落有方位含义的东西**：

| 落盘 | 依据 |
| --- | --- |
| 后天八卦八方位（四正坎震离兑、四隅艮巽坤乾） | 固定骨架；四隅同时就是二十四山里的四个维，所以只出现一次 |
| 十二支 + 八干 = 二十四山刻度 | 固定刻度；这一盘用到的位标朱 |
| 四柱干支连线 | 起笔圆点在天干格，折入后沿同一半径绕到地支格，箭头落支上 |
| 空亡戌亥 | 两格下沿虚弧 |
| 巳午半会火 | 两支之间加粗的一小段 |
| 五行计数（水北木东火南金西，土居中） | 与下面「五行分布」同一组数 |

连线要点：

- **四条线用四个半径**（121 / 111 / 101 / 93），年最外、时最内。庚与午各被两柱用到，不靠半径错开就会重线。
- **起止角就是真实格位**，只有收笔那几度（午位 175 / 185，辰位 123）为避让箭头做了偏移，箭头才能分辨是两条。
- **柱名不进盘**。盘内没有空地，硬塞会压字；改成盘下一条图例 `年 庚→午 · 月 辛→巳 · 日 庚→辰 · 时 壬→午`，顺序与半径由外到内一致。
- **不画以太极为心的整圆**：八字没有「命宫居中」这种结构，中心只放日主与强弱，避免读者把盘当紫微命盘看。

不落盘：十神、神煞、藏干。前两者落点随派别与取用变，写死会变成假数据；藏干在下面的四柱表里已有。

| 位置 | 做法 |
| --- | --- |
| 页头 | 一行：返回 ‹ ｜页名（横排 17px）｜单字章（26px、1px 朱框）。十三屏同一套，不再有竖排刊头 |
| 底栏 | 四项 `今日 / 命盘 / 运势 / 我的`，21px 线性图标 + 11px 字，当前项朱色。沿用旧版 `design/miniprogram` 的图标语义 |

页头的章只作标记（命/柱/盘/日/年/月/运/宫/合/起/录/本/文），不当按钮；页内动作一律走正文按钮。

## 已知取舍

- D 已铺满十三屏（今日 / 八字 / 紫微 / 流日 / 流年 / 流月 / 大限 / 宫位 / 合盘 / 出生信息 / 记录 / 我的 / 报告）。
  E、F 停在比稿的三屏，作为落选方向留在目录里对照，不再往下铺。
- 竖排（E）在窄列里放不下多位数字，所以岁数一律横排；这是排版取舍不是数据缺失。
- 对比度、横向溢出、文字裁切、字号过小由 `.pair/lab2-audit.cjs` 在 390×844 下逐屏量，十三屏当前全过；
  改版后先跑它，再看 `.pair/lab2-shots/` 里的实屏图确认视觉。审计只量机械指标，重叠、错位、语义重复要人眼看。
- 页头统一一套：返回 ‹ ｜页名 ｜单字章。根页（今日 / 八字 / 紫微）不带返回，其余带。
  页内动作放正文按钮（`再排一盘`），不在页头再放一份。
- 命盘宫格内每项都 `nowrap`：主星后跟亮度的方框、辅星、岁前小限都是一行，超出的用省略号而不是折行，
  折行会把「十恶大败」这类四字神煞拆成两行。
- **中心不空、也不跟判据抢位置**：盘心是太极（36px，`opacity:.18` 的 S 形分割）+ 一圈爻线（乾兑离震巽坎艮坤，后天方位，阴爻断开），纯装饰；日主、强弱、格移到这一段的标题右侧，不放盘里。
- 页头与底栏由 `.pair/gen-chrome.cjs` 统一生成（幂等），改导航只动这个脚本。
- 触屏点击不高亮黑块：`-webkit-tap-highlight-color: transparent`，`:active` 用极淡朱色底或透明度变化，不用系统默认底色。
