# 三套小程序版式方案（lab）

三个方向、同一份数据、同一批三屏（今日 / 八字 / 紫微），**只做版式，不做配色**。
配色随便，判断标准是：截图并排放在一起，不看颜色也能一眼看出是三套不同的设计。

## 怎么看

```powershell
# 服务已在 8765，直接打开
start http://127.0.0.1:8765/mp/lab/a-instrument-home.html
start http://127.0.0.1:8765/mp/lab/b-editorial-home.html
start http://127.0.0.1:8765/mp/lab/c-native-home.html
```

每套三屏：`-home`（今日）、`-bazi`（八字）、`-ziwei`（紫微）。视口按 390×844。

## 三套

| 目录前缀 | 方向 | 一句话 |
| --- | --- | --- |
| `a-instrument` | 仪表盘 | 去掉所有卡片边框，靠图表、粗数字、细网格线说话；紫微画真盘，八字画柱。 |
| `b-editorial` | 杂志编辑 | 不用边框和卡底，只有字和细分隔线；大标题、章节编号、双栏、大量留白。 |
| `c-native` | 原生应用 | iOS 分组列表 + 大标题 + 分段控件 + 底部 tab；最稳、最像微信自带应用。 |

## 文件

```
lab/
  base.css                三套共用的最小 reset（盒模型、字体栈、禁横向滚动），不含视觉风格
  a-instrument.css        A 套
  b-editorial.css         B 套
  c-native.css            C 套
  {a,b,c}-{home,bazi,ziwei}.html
```

## 数据

三套用的都是同一份真实样本：1990-05-15 12:30 男 · 上海 · 真太阳时 12:33 · 庚午年四月廿一日午时。
四柱 庚午 / 辛巳 / 庚辰 / 壬午，紫微土五局命宫亥，2026 丙午虚岁 37。

数字与文字都是排盘引擎算出来的，写死在 HTML 里是因为这是**静态设计稿**，不接后端。

## 注意

- 这三套**没有替换** `design/miniprogram/` 现在的 13 屏，是并排的方案，选完再铺开。
- 三套都只做了三屏，其余十屏（流年/流月/流日/合盘/记录/我的/报告等）等选定方向后再补。
- 没有交互（没有 JS）：切换、展开、跳转都没有画。
