# M4 前端视觉原型交付记录

日期：2026-10-25

## 交付范围

- 新增本地网页工作台，使用原生 HTML、CSS、JavaScript。
- 新增 Python 标准库 HTTP 服务与 `/api/v1/bazi/calculate` 接口。
- 页面直接调用真实八字适配层，不使用硬编码排盘结果。
- 支持公历/农历、分钟/时辰/未知时间、排盘性别、出生地标注。
- 展示四柱、日主、大运、流年、警告、规则配置与固定引擎来源。
- 完成桌面端和 390px 移动端响应式布局。

## 视觉方向

本轮采用“节律历表”：矿物灰纸、深墨青、克制朱砂、细规则线和接近直角的工作台结构。避免星空、卷轴、符咒、渐变和深色玄学仪表盘。完整方向见 `docs/design-direction-v1.md`，当前仍待用户确认。
