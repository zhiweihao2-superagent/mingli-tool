# 文墨天机常量表（对账用）

## 这是什么

从 `文墨天机电脑版_Win_2.0.15.zip` 里抽出的**数据表**，用作本引擎的外部对照源。

来源链：

```
文墨天机电脑版_Win_2.0.15.zip (19,672,816 B, 8 entries)
└─ 安装第2步：ZiWeiDesktop.air (11,895,982 B)        ← Adobe AIR 包
   └─ ZWDesktop.swf (11,812,229 B, ZWS/LZMA 压缩)
      └─ 解压后 FWS (15,406,419 B)
         └─ FFDec 26.4.0 反编译 → 618 个 ActionScript 类
            └─ GlobalConsts.as (122,920 B)            ← 全部规则表在这里
               └─ extract_tables.py → tables.json (224 张表)
```

## 怎么用

```powershell
node scripts/crosscheck_wmt_tables.cjs   # → docs/wmt-crosscheck.md
```

## 它把「争议口径」写成了配置项

这是这个包最有价值的部分：哪一派怎么算，被写成显式选项，默认值就是它的标准盘口径。

- **庚干四化 5 派**（`pp_cfg_sihua_*`）：阳武阴同（默认）／阳武同阴／阳武府同／阳武府相／阳武同相
- **天魁天钺 4 派**（`pp_cfg_kuiyue1..4`）：六辛逢虎马（默认）／庚辛逢马虎／庚辛逢虎马／六辛逢马虎
- **星曜亮度 4 套**：斗数全书（默认）／中州派／现代修订一／现代修订二；已抽成 `knowledge/wmt/brightness.json`（`schema: wmt-brightness/v1`，每颗星 12 位数字，子→亥，`1 庙 2 旺 3 得 4 利 5 平 6 不 7 陷`，`0 = 该派不赋值`）
- 截空旬空 3 法、长生十二神 3 法、小限 3 法、命主 2 法、天使天伤 2 法、天空 2 法、天马（年支/月支）
- 闰月（本月/下月/月中分界）、晚子时（当日/次日）
- 安星方法：飞星／三合（默认）／四化

## 边界

- 这是**数据表**，不是算法。表里的值我们只能拿来比，不能拿它替我们算盘。
- 该软件不是本项目的依赖，也不随仓库分发；`tables.json` 只含数值常量与短标签。
- 表名是混淆变量名（`_AX_*`），语义靠数值特征与配置标签反推，个别未确认的已在
  `tables.json` 里保留原样，不做猜测性改名。
